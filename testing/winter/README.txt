Зимний дизайн v2 — локальная проверка

Сборка из корня репозитория:
  ./testing/winter/build-design-preview.ps1
При необходимости передать -ToolRoot, -RuntimeRoot и необязательный -PersonalAssets.
Личный пресет допустим только для локального debug APK. Такие APK не публикуются.

Установить runtime/winter/build/app/outputs/apk/debug/app-debug.apk командой
  adb -s <serial> install -r <apk>
Запуск:
  adb -s <serial> shell am start -n team.kotiki.app.winterpreview/team.kotiki.app.WinterPreviewActivity

Пакет team.kotiki.app.winterpreview независим от основной установки.
В нём открываются настоящие доска, планы, календарь, заметки и настройки.
Чат — локальный стенд тех же MessageBubble; доставку сообщений эта проверка не тестирует.
Облачные аккаунты и Firebase не используются. Данные стенда можно удалить отдельно.

Проверки:
- на доске есть компактная строка «Снег идёт», лес на фоне всех основных экранов, снег движется, кнопка отключает и включает его;
- снежинки не перехватывают нажатия на события, меню и поля;
- календарь, планы и заметки открываются, редакторы принимают ввод;
- заметка сохраняется после перезапуска; общий/личный доступ не меняется темой;
- чат показывает входящее/исходящее сообщение и редактор сообщения;
- переход в фон прекращает отрисовку; возврат возобновляет без скачка;
- системный animator_duration_scale=0 останавливает снег, значение после проверки восстановить;
- обычный release содержит WINTER_PREVIEW=false и не содержит WinterPreviewActivity;
- при выключенном Remote Config в обычных настройках нет выбора зимней темы; после удалённого запуска тема применяется автоматически.

Отчёты, скриншоты, логи и личные сведения — только testing/local/034/.
Нельзя использовать этот тестовый APK для публикации или как обновление основной установки.

0.3.5: в локальном preview доступен четвёртый вариант оформления «Зима вместе» в Настройки → Оформление. При первом запуске этой версии выбрана светлая тема; последующий выбор сохраняется на устройстве. В обычном APK этого варианта выбора нет, действует только удалённая активация.
