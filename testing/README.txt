Тестирование

unit/java/ — автоматические тесты модели и UI-сценарий Robolectric.
emulators/ — настройка двух AVD, запуск, установка APK, остановка; инструкция README.txt.
presets/example.json — обезличенный пример локального пресета.
local/ — личные пресеты, отчёты, снимки и журналы. Папка полностью исключена из Git.

Личный пресет
Скопируйте presets/example.json в local/presets/<имя>/local-test-preset.json.
Перед локальной сборкой задайте KOTIKI_TEST_ASSETS как абсолютный путь к этой папке.
Ресурс подключается только в debug. Без переменной собирается обезличенная демоверсия.
APK с личным пресетом содержит его имена и данные: такой APK предназначен только для личного использования.

В пресете: id (латиница/цифры/дефис), names.USER_1/USER_2, defaultUser, theme,
retentionDays, entries, plans, lists. dayOffset задаёт день относительно первого
запуска профиля; null — без дня; durationDays — длительность включительно.
Это демонстрационные примеры, а не импорт настоящего календаря.

При наличии пресета в Настройках можно переключать два тестовых профиля.
У каждого отдельное локальное сохранение. Изменение пресета с тем же id не стирает
сохранённые записи. Для нового набора исходных данных задайте новый id.
Это локальное демо. Облачный режим включается отдельной конфигурацией Firebase и требует авторизации; демо в облако автоматически не копируется.

Команды из корня репозитория:
.\gradlew.bat testDebugUnitTest
.\gradlew.bat testDebugUnitTest --tests team.kotiki.app.DemoModelsTest
.\gradlew.bat lintDebug

Перед ручной проверкой: собрать assembleDebug, установить через emulators/android-devices.ps1.
SDK, AVD-диски, Gradle-кэш и результаты сборки находятся в отдельном окружении.
Для параллельных агентов используйте разные ADB serial, как описано в emulators/README.txt.

Регрессии 0.1.3: DemoStoreTest проверяет удаление, отмену, права, миграцию личных демотем и устойчивый порядок изменений. AppSmokeTest проверяет возврат на выбранную неделю/фильтр и сохранение черновика при пересоздании Activity.
Ручной сценарий: обзор → следующая неделя → календарь → доска; выбор дня → лента; 7+ тем → две строки/Ещё → изменение скрытой темы → повторный вход; удаление/отмена; шрифт 150% → меню; попытка поворота телефона.

Галерея коллекций
presets/collection-gallery.json — обезличенные дополнительные темы/списки с пунктами. Для личного debug-пресета положите копию рядом с local-test-preset.json. Галерея применяется один раз на revision для каждого профиля, сохраняет существующие группы и не восстанавливает удалённые пользователем демогруппы при последующих запусках.

Кириллица в эмуляторе с клавиатуры компьютера
В Gboard → Languages добавьте Русский (Россия), сохранив English (US). В Android → Physical keyboard для соответствующих языков должны быть English (US) и Russian (automatic). Переключение внутри окна эмулятора — Ctrl+Space. Раскладка Android отдельна от раскладки Windows.
В 0.1.4 проверены ввод Unicode через компьютер, физическая клавиша в русской раскладке, создание темы с кириллицей и сохранение после пересоздания Activity.

Общий сбор 0.1.5
GatheringTest: обязательные дата/время, фиксированные тип/участники, запрет невалидной записи, сохранение/перезагрузка, отсутствие уведомления автору при сохранении, отдельный канал и точный адрес перехода из уведомления, скрытые подробности на экране блокировки.
AppSmokeTest: упрощённая форма, отсутствие переключателей, обязательная дата, сохранение черновика после пересоздания Activity. На небольшом экране используется прокрутка формы.
Ручной сценарий: Общий сбор → сохранить без расписания → выбрать дату и начало/окончание → сохранить → календарь (сердце и отдельная карточка) → Зовут/От меня → подробности → Проверить уведомление → отказ/разрешение → шторка → открыть уведомление. Проверять только на одном локальном устройстве, не выдавать пример за доставку второму участнику.
Документация Android: https://developer.android.com/develop/ui/compose/notifications/create-notification

Принятие приглашения с доски
InvitationAcceptanceTest: сохранение/перезапуск и отмена, запрет принятия исходящего/закрытого/чужого приглашения, защита от повторного или устаревшего действия. AppSmokeTest: принятие непосредственно в ленте дней, отмена, принятие в обзоре недели.
Ручная проверка: сохранить резервную копию личного пресета; входящее приглашение → Принять → обычная яркость/история → Отменить; исходящее без кнопки. После проверки восстановить исходные данные, не оставлять ответ пользователя за него.

Проверки 0.3.0
- unit/: AppLockTest, InviteWorkflowTest, VisibilityCreationTest, AndroidPushTest, LocalRemindersTest, CalendarExportTest.
- firebase/: серверные права, неизменность видимости, приватность, история, приглашения, чат задач, регистрации устройств, атомарная push-очередь.
- push/: доставка и повторы, недействующие участники, приватные данные, ограничения запросов, пакетное чтение, запрет HTTP-перенаправлений.
- local/agents/: личные UI-сценарии двух независимых эмуляторов. Не публиковать их данные, снимки, UID или отчёты.
Реальные OAuth и CalDAV требуют подключения владельцем аккаунтов. Фиктивный HTTP transport в unit-тестах не считается реальным экспортом.
