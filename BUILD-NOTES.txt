Kotiki team — конфигурация первой Android-сборки

Зафиксированные версии:
• Java: Eclipse Temurin JDK 21, актуальная сборка получена через официальный API Adoptium.
• Gradle: 8.13.
• Android Gradle Plugin: 8.13.2.
• Kotlin и Compose Compiler plugin: 2.2.21.
• Compose BOM: 2025.10.01.
• AndroidX Activity Compose: 1.11.0; Core KTX: 1.17.0.
• compileSdk и targetSdk: 36; minSdk: 28.
• Android SDK Build Tools: 35.0.0.
• Локальные проверки запуска: Robolectric 4.17 и Compose UI Test на Android API 35.

Совместимость AGP, Gradle, JDK и API сверена с официальной документацией:
https://developer.android.com/build/releases/agp-8-13-0-release-notes

Схема подключения Compose Compiler, совпадающего по версии с Kotlin:
https://developer.android.com/develop/ui/compose/setup-compose-dependencies-and-compiler

Android SDK и установка компонентов:
https://developer.android.com/studio

Командные инструменты 19.0 используются для совместимости с изолированной средой Windows. Версия 23.0 попыталась обратиться к недоступному разделу реестра через Android CLI.

Проверки Android без подключённого телефона:
https://robolectric.org/getting-started/

В этой сети основной адрес Maven Central возвращает 404 для существующих артефактов. Добавлено HTTPS-зеркало Maven Central, размещённое Google:
https://maven-central.storage-download.googleapis.com/maven2/

Официальные источники дистрибутивов:
https://api.adoptium.net/v3/assets/latest/21/hotspot?architecture=x64&image_type=jdk&os=windows&vendor=eclipse
https://services.gradle.org/distributions/gradle-8.13-bin.zip

Архивы JDK и Gradle проверяются по SHA-256 источника. Архив командных инструментов Android — по контрольной сумме из официального XML-репозитория Google. Лицензии инструментов приняты в рамках явного согласия пользователя на установку.

Новые версии зависимостей не подставляются автоматически. Текущий документ не означает, что выбраны самые новые версии всех библиотек.

Раздельное хранение исходников и окружения:
build-local.ps1 поддерживает ToolRoot и RuntimeRoot; локальные значения читаются из игнорируемого build.local.json. KOTIKI_RUNTIME_DIR перенаправляет сборочные результаты и тестовые каталоги. Для прямого вызова Gradle без этого скрипта остаются стандартные пути.
