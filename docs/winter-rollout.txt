Зима вместе — дизайн v2, APK 0.3.5

Тема встроена в APK. Пользовательского переключателя зимней темы нет.
Remote Config: winter_together_enabled, тип Boolean, значение по умолчанию false.
При true тема автоматически применяется при открытии / возврате приложения.
При false возвращается выбранная ранее светлая, тёмная или системная тема.
Первое открытие без сети использует обычную тему. При последующих открытиях
без сети используется последняя успешно активированная конфигурация.
Проверка при ON_START, minimumFetchInterval 60 секунд, timeout 8 секунд.
Нет постоянного live-listener: длительно открытый редактор не перекрашивается
из-за удалённой публикации. При открытии возможна смена темы после получения ответа.

Поздний запуск: Firebase Console → Remote Config → winter_together_enabled → true
→ Publish changes. Откат: false → Publish changes. После публикации открыть приложение
с интернетом; если конфигурация проверялась менее минуты назад, дождаться следующего
открытия после истечения этого интервала. Уже установленный APK 0.3.5 обновлять не надо.
Более ранние APK без интеграции этот флаг не читают.
Не хранить секреты или персональные данные в Remote Config.

Визуальная версия: фон заснеженных елей на всех основных экранах, полупрозрачные
карточки, компактный переключатель снегопада. У записей 2–5 тонких сосулек длиной
8–22 dp, шириной 5–9 dp; рисунок детерминирован по ID, не зависит от текста и порядка.
Декор не перехватывает нажатия. Сосульки показываются только у последней карточки,
если хватает стандартного промежутка; дополнительных отступов не добавляют.
Анимация останавливается в фоне и учитывает системное отключение анимаций.
Системная нижняя панель прозрачная; кнопки и safeDrawing-отступы сохранены.

Тестовая сборка .winterpreview позволяет выбрать тему в настройках независимо от удалённого флага,
не подключает Firebase и не публикуется вместо основной версии.
