Фирменная графика Kotiki team

symbol.svg — знак для шапки приложения; emblem.svg — знак с надписью в контурах для открытия.
Варианты -light используются на тёмном фоне. app-icon.svg — исходная квадратная иконка.
launcher-foreground.svg — увеличенный и отцентрированный знак без квадратного фона; фон и маска адаптивной иконки задаются Android.
Все исходники выбранного комплекта сохранены в векторе. Конвертация: python graphics/tools/svg_to_vector.py.
Размеры и пропорции знака сохраняются через ContentScale.Fit. Функциональные мордочки карточек находятся отдельно в graphics/icons: cat-face.svg, cat-girl.svg и pair.svg.
